# v0.3 演示脚本

按 P01–P11 记录现场证据。开发机测试、解压候选包、编译通过和云端接口返回都不能替代新 Mac 验收。

## 正常主流程

- 新 Mac 架构为 arm64；Skill 从选定 GitHub 仓库安装。
- Connector 登录后端运行，能看到当前 Codex account/read、真实项目和两个已确认任务。
- 电脑生成 8 位码；设备显示等待提示，按住说码后显示识别中、正在绑定、绑定成功。
- 设备重启后绑定仍在；任务 A 的电脑输入和设备输入都回到同一 `threadId`。
- 任务 B 的新回复在设备空闲时提醒；A 录音和确认期间不切换目标。
- 解绑取消无变化；确认后云端立即拒绝旧绑定，在线设备回待绑定，离线设备显示待联网同步。
- 新码重新绑定；旧绑定的待发消息和未读提醒不进入新绑定。

## 记录字段

记录 Connector/SaaS/固件版本、包 SHA-256、macOS/Codex 版本、设备标识、测试时间、`bindingId`、`epoch`、`threadId`、消息和执行回执；不要记录 token、bootstrap secret 或完整私人对话。
